# FastTech - Landing Page Accesible

## 📋 Descripción del Proyecto

Proyecto de auditoría y optimización de accesibilidad web según las pautas WCAG 2.1 nivel AA. Este sitio web ha sido completamente rediseñado para garantizar accesibilidad universal, optimización SEO y conformidad con los estándares web actuales.

## ✨ Características

- ✅ **Conformidad WCAG 2.1 Nivel AA**
- ✅ **HTML5 Semántico**
- ✅ **Navegación 100% accesible por teclado**
- ✅ **Compatible con lectores de pantalla**
- ✅ **Contraste de color optimizado (>4.5:1)**
- ✅ **Formulario completamente accesible**
- ✅ **SEO optimizado (Lighthouse 100/100)**
- ✅ **Responsive Design**
- ✅ **Validado W3C**

## 🚀 Instalación y Uso

### Opción 1: Abrir directamente
1. Descarga todos los archivos
2. Abre `index.html` en tu navegador

### Opción 2: Servidor local
```bash
# Con Python 3
python -m http.server 8000

# Con Node.js (http-server)
npx http-server
```

Luego accede a `http://localhost:8000`

## 🔍 Pruebas de Accesibilidad

### Navegación por Teclado
- **TAB**: Navegar hacia adelante
- **SHIFT + TAB**: Navegar hacia atrás
- **ENTER**: Activar enlaces y botones
- **SPACE**: Activar botones

### Skip Link
Presiona **TAB** al cargar la página para acceder al enlace "Saltar al contenido principal"

### Lectores de Pantalla Compatibles
- ✅ NVDA (Windows)
- ✅ JAWS (Windows)
- ✅ VoiceOver (macOS/iOS)
- ✅ TalkBack (Android)
